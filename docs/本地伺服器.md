# D2 Survivors 本地伺服器

## 為什麼能整個搬回本地
- D2 Survivors 網頁版是**純前端**：遊戲邏輯全部在瀏覽器跑，存檔在瀏覽器 localStorage／OPFS。
- 網站上的東西分三種，全部處理了：

| 東西 | 來源 | 本地怎麼處理 |
|---|---|---|
| 遊戲程式、頁面（play/、setup.html、wiki、faq…） | `https://d2survivors.lol/` | `tools/mirror_assets.js` 全站鏡像（約 360 檔） |
| Diablo II 素材（圖、音效、地圖） | 官方代管在 `/d2/`（`site.json` 的 `hostedFiles:true`） | `tools/mirror_d2.js` 完整下載；沒下載的檔伺服器會即時補抓 |
| 排行榜 | `/api/leaderboard/...` | 轉送官方；`--offline` 時回 503（遊戲顯示離線，其他照玩） |

## 本地伺服器做的事（`tools/local_server/server.js`，零依賴）
- `/play/`、`/play/setup.html`：送鏡像頁面，並在 `</head>` 前插入：
  `window.__D2ZH_LOCAL=1; window.__D2ZH_BASE='/d2zh/'` ＋ DOMContentLoaded 後載入 `/d2zh/d2_zh.js`（跟電腦版注入一樣）。
- `/d2zh/`：專案根目錄的 d2_zh.js、回應.txt、教學頁、desktop/（白名單），帶 CORS＋`Access-Control-Allow-Private-Network`
  → 在官方網站點書籤也能從本機載入。
- 其他路徑：`_research/mirror/`，沒有就向官方抓並存起來（記在 `_research/mirror/更新紀錄.txt`）。
- 帶雜湊的打包檔給長快取，其他 no-cache。

## 限制
- **只能用 localhost / https 玩**：遊戲用 OPFS 和 Service Worker，瀏覽器只在安全環境開放；`http://192.168.x.x:8790` 開得起來但讀不到素材。
  朋友要玩：在他電腦放一份專案資料夾自己開；或用 https 反向代理（例如 Tailscale Serve / Cloudflare Tunnel）。
- 存檔跟網址綁定：localhost:8790 和官方網站是兩份存檔。用遊戲內的存檔轉移搬。
- `/d2/` 素材只留最新版；回滾舊版遊戲若用到不同素材，要連網補抓。

## 遊戲改版時
`更新遊戲.bat` = 
1. `node tools/mirror_assets.js`：入口檔重抓成官方最新，新的打包檔補進來；舊入口備份到 `_research/mirror_versions/<版本>/`
2. `node tools/mirror_d2.js`：依 `d2-files.hashes` 比對 `_research/mirror/d2/.hashes.json`，官方改過的資料夾重抓
3. `node tools/check-update.js`：列出書籤還沒翻到的新字串、進化表差異（報告在 `tools/cache/`）

然後照報告改 `d2_zh.js`，升版本號、寫 D2ZH_NEWS。
